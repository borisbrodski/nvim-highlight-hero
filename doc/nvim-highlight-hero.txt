1. INTRODUCTION                                        *highlight-hero-intro*

nvim-highlight-hero highlights multiple words, selections and whole lines in
distinct colours, either on demand into numbered groups or live as the cursor
moves. It is useful for spotting typos, following a variable's uses, and
resolving merge conflicts by matching lines while ignoring indentation
(|highlight-hero-merge|).

==============================================================================
2. REQUIREMENTS                                 *highlight-hero-requirements*

Neovim >= 0.10 (uses `vim.fn.getregion`).

==============================================================================
3. SETUP                                               *highlight-hero-setup*

Call setup() once. It installs the keymaps, the commands and the highlight
groups. >lua
    require("nvim-highlight-hero").setup()
<
See |highlight-hero-config| for options.

==============================================================================
4. COMMANDS                                         *highlight-hero-commands*

                                                                         *:HH*
:HH [N] [text]      Highlight the word under the cursor, the visual selection
                    (with a range, e.g. `:'<,'>HH`), or the literal [text],
                    into group [N] (0-9, default 0). Repeating the same target
                    toggles that group off. Strong matching: whole word,
                    smartcase.

                                                                        *:HH!*
:HH! [N] [text]     As |:HH| but weak matching: substring, case-insensitive.

                                                                      *:HHoff*
:HHoff [N]          Clear group [N]. With no argument, clears the group you
                    set most recently.

                                                                     *:HHoff!*
:HHoff!             Clear every group.

                                                                     *:HHauto*
:HHauto             Toggle live auto-highlight: continuously highlight the
                    word under the cursor or the current selection, updating
                    as you move. `:HHauto!` uses weak matching. By default
                    the highlight is mirrored into every other (non-floating)
                    window of the current tab page; set `auto.all_windows`
                    to false to keep it to the current window.

                                                                   *:HHcolors*
:HHcolors           Open a preview of the palette for the current background.

==============================================================================
5. KEYMAPS                                           *highlight-hero-keymaps*

Default maps (all configurable, see |highlight-hero-config|):

    <leader>h0 .. <leader>h9   Toggle the word (normal mode) or selection
                               (visual mode) in group 0-9.
    <leader>hh                 Toggle live auto-highlight (strong).
    <leader>hH                 Toggle live auto-highlight (weak).
    <leader>ho                 Clear the last group you set.
    <leader>hO                 Clear all groups.

==============================================================================
6. MATCHING                                         *highlight-hero-matching*

Two presets combine three choices (word-boundaries, case, whitespace):

    strong (|:HH|, digit maps)   whole word, smartcase.
    weak   (|:HH!|)              substring, case-insensitive.

For a visual selection, word boundaries never apply. A linewise or multi-line
selection uses "merge" whitespace matching: leading indentation and trailing
whitespace are ignored and each line is anchored, so the selection matches the
same lines at any indentation. A single-line characterwise selection matches
literally.

==============================================================================
7. MERGE CONFLICTS                                     *highlight-hero-merge*

To see which conflict lines differ only by indentation:

1. Turn on auto-highlight: <leader>hh
2. Linewise-select one line with `V`.

Every indentation-variant of that line lights up. A line whose highlight does
not appear on another branch is one that actually changed. Narrow down a
partial change by selecting characterwise and watching where the highlight
stops.

==============================================================================
8. COLOURS                                             *highlight-hero-colours*

Groups 0-9 use `NvimHighlightHero0`..`NvimHighlightHero9`; the live
auto-highlight uses `NvimHighlightHeroAuto`.

The default palette is built on the Okabe-Ito colour-blind-safe set and used
as background colours. Each foreground is chosen for a contrast ratio of at
least 4.5:1, a 256-colour fallback is computed, and a light-background variant
deepens the hues. The palette is tested to stay distinguishable under
simulated deuteranopia and protanopia.

Override colours per group with the `colors` option
(|highlight-hero-config|), or define the highlight groups yourself (they are
set as defaults, so your definitions win).

==============================================================================
9. CONFIGURATION                                       *highlight-hero-config*

Defaults: >lua
    require("nvim-highlight-hero").setup({
      prefix = "<leader>h",            -- digit maps: prefix .. 0..9
      keymaps = {
        toggle_auto = "<leader>hh",
        toggle_auto_weak = "<leader>hH",
        off_last = "<leader>ho",
        off_all = "<leader>hO",
      },
      set_default_keymaps = true,      -- false to map everything yourself
      auto = {
        all_windows = true,            -- false: current window only
      },
      -- colors = { [0] = "#E69F00", auto = "#50566B" },
    })
<
==============================================================================
10. API                                                  *highlight-hero-api*

>lua
    local hh = require("nvim-highlight-hero")
    hh.highlight(n, "strong"|"weak", { source = "word"|"selection",
                                       text = "...", append = true })
    hh.off(n)          -- clear group n
    hh.off_last()      -- clear the last group set
    hh.off_all()       -- clear all groups
    hh.auto_toggle("strong"|"weak")
    hh.auto_enable("strong"|"weak")
    hh.auto_disable()
<
